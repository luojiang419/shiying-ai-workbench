# AutoDL.Art 镜像提交资料

**产品名称**：诗影 AI 工作台

**镜像标识**：`shiying-ai-workbench-h3`（平台仅接受字母、数字及 `-_.`；展示品牌为“诗影 AI 工作台”）。

**简短介绍**：MiniMax H3 驱动的视频与素材克隆工作台，支持多参考素材、DeepSeek Flash 指令优化、任务队列及作品管理。开机打开网页即可创作，AI 助手使用用户自己的 Key。

**功能介绍**：

诗影 AI 工作台将 H3 视频创作、素材克隆、AI 提示词优化和作品管理整合到统一网页。用户可上传参考图片和视频，选择分辨率、时长、步数及 Seed，并通过文字描述目标编辑。克隆流程使用用户自己的 DeepSeek Flash Key 分析素材、整理替换关系，再调用 H3 生成视频。

应用提供自动启动与动态地址适配，不需要沿用发布者的域名。默认不收集节点信息，不内置发布者 API Key。生成结果取决于模型和素材，快速动作、遮挡及复杂编辑仍可能出现不稳定。

首版为视频与克隆版，不包含 Qwen-Image 2.1 图片生成服务；MiniMax H3 和其他依赖遵守各自许可。

**分类建议**：视频 / MiniMax H3 / 克隆 / 创作工具。

**网页服务端口**：6008。

**已验证环境**：PyTorch 2.12.1、CUDA 13.0；系统盘 30GB，当前使用约 17GB，H3 大型模型通过公共库挂载。

**启动命令**：`bash /root/zealman-app/scripts/improved-autostart.sh`

**推荐配置**：32GB 或更高显存 NVIDIA GPU，优先使用已验证的应用系统镜像；需保留 H3 公共模型挂载。大模型无公共挂载时应另备足够存储。

**首次使用**：访问 `/setup/`，在本实例终端获取管理码，配置自己的 DeepSeek Flash Key。

**源代码地址**：https://github.com/luojiang419/shiying-ai-workbench
