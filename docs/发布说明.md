# 镜像发布与维护

## 发布内容

应用名称：诗影 AI 工作台。首版仅提供 MiniMax H3 视频创作和素材克隆。

源码、部署脚本、使用说明和 SHA-256 构建凭据放 GitHub；完整系统镜像在 AutoDL 平台保存。请勿把私有配置、备份、模型或完整运行环境放入 GitHub。

## 当前镜像启动和首次配置

系统盘保留后端 `/root/minimax-node`、ComfyUI `/root/minimax-comfy` 及现有运行环境。关键入口：

- `deployment/run_service.py` 的 API 分支启动 `app.public_server`。
- `deployment/start-node.sh` 拉起 Supervisor，关闭后台进程继承的启动锁，并等网关就绪。
- 平台开机命令调用 `improved-autostart.sh`，其中调用上述启动脚本。
- 公网网关由 `gateway.cjs` 和 `platform-origin.cjs` 动态校正当前实例 Host/端口，保留 Origin 校验。

新用户在 `/setup/` 输入终端获取的管理码和自己的 Flash Key。管理码不是发布者的个人密码，不通过公开 API 返回。

## 保存前

先备份私有配置，再停止所有生成任务。由实例所有者运行脱敏脚本：

```bash
cd /root/minimax-node
venv/bin/python deployment/public_image.py --redact-personal --clean-home
```

此操作删除当前实例中的个人助手配置、解密文件、配置备份、私人监控凭据、任务与上传数据；适用于明确要转成公开镜像的制作机。完成后仍应检查用户自行添加的其他应用凭据和素材。

确认界面品牌正确、图片生成功能未开放、助手处于未配置状态；无测试任务，模型依赖就绪，开机入口恢复/重入正常。保存当前系统盘为新镜像，再在新实例验证首次启动。`public-owner.json` 即使随镜像保存，新实例也会按本次 AutoDL 实例 ID 换发管理码。
