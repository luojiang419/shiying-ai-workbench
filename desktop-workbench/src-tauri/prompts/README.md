# H3 提示词规则

`base-cn.txt`、`ref-cn.txt` 来自本机 `C:/Users/jiang/.codex/skills/h3-prompt-writing/references/`，于 2026-09-15 随桌面程序内置。规则通过 Rust `include_str!` 打包，不依赖用户安装目录。

- 首尾帧/纯文本使用 base；多参考模式使用 ref。
- 优化接口接收用户提示词、时长、素材清单和按顺序压缩的真实参考图片；图片通过多模态请求同步解析，视频和音频只提供文件清单，不声称已经识别其内容。
- 用户提示词为空时进入“智能创作”，按图片顺序推导连贯故事；有提示词时始终优先保持用户的导演意图。
- 自动解析和润色复用无限画布的视频导演规则：输出必须包含连续动作节拍、主导运镜和与时长匹配的收束；结果会校验 H3 字段、图片覆盖和 7000 字符上限，不合格时自动修复一次。
- Responses 与 Chat Completions 返回文本均支持；多个已启用配置按保存顺序失败切换。Azure 专用部署/API version 协议暂不支持。
- API Key 使用 Windows DPAPI 加密后保存在本机配置中，密文绑定 Windows 账户；迁移到其他账户需要重新填写。
